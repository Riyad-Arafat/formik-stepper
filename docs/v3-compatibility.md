# Formik Stepper v3 Compatibility Policy

## Supported targets

| Dependency | v3 target | Policy |
| --- | --- | --- |
| React | 18 and 19 | Both majors remain supported through the v3 line. |
| React DOM | 18 and 19 | Must use the same major as React. |
| Formik | 2.4 | The initial v3 release targets the maintained Formik 2 API. |
| TypeScript | 6.x declarations | The package publishes declarations generated by the repository compiler. |

React 19 is the active development and unit-test environment. Dedicated React 18 and React 19 consumer fixtures are required before the v3 release candidate; that verification belongs to Task 5 of the v3 plan.

## Compatibility rules

- A React or Formik compatibility change requires a major release unless it only widens support.
- Headless imports must not require default UI styles.
- Importing the package must remain safe in server-rendered environments.
- Public types, stable step IDs, and render-slot contracts are part of the supported API.
- The v2 demo remains unchanged until the documented migration phase.
